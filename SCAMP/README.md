# Relish — Landing Page

This is a lightweight static landing page prototype for a food ordering platform.

What's included:
- `landingpage.html` — main markup with hero, menu, cart and navbar
- `landingpage.css` — styles and responsive rules
- `assets/` — suggested place for images and brand assets

How to view locally:
1. Open `landingpage.html` in your browser.

Notes and next steps:
